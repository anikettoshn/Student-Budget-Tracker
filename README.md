# Student-Budget-Tracker
A Java application for tracking student expenses and budgets.
Project Goal

Build a Java application that helps college students manage their spending and stay within their monthly budgets.

Minimum Viable Product (MVP)

Record expenses with descriptions, categories, and amounts.

Calculate total spending and remaining budget.

Save and load expenses using CSV files.

Tech Stack

Language: Java

IDE: Visual Studio Code

Libraries: Scanner, ArrayList, FileWriter, BufferedReader

Data Storage: CSV files

Version Control: Git and GitHub

External APIs: None

Future Plans (V2.0)

Generate monthly spending reports.

Set spending limits for individual categories.

Display spending graphs and charts.
